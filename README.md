### Prerequisites

| Tool | Version | Download |
|---|---|---|

| PostgreSQL | 13 + | [postgresql.org](https://postgresql.org/download) |

---

### Step 1 — Clone & Install

```bash
# Clone the repository
git clone https://github.com/yourusername/ecommerce-analytics.git
cd ecommerce-analytics

# Create and activate a virtual environment
python -m venv venv

# Windows
venv\Scripts\activate

# macOS / Linux
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt
```

---

### Step 2 — Configure PostgreSQL

1. Open **pgAdmin** or **psql** and create the database:

```sql
CREATE DATABASE ecommerce_analytics;
```

2. Copy `.env.example` → `.env` and fill in your credentials:

```bash
cp .env.example .env
```

```env
DATABASE_URL=postgresql://postgres:yourpassword@localhost:5432/ecommerce_analytics
GEMINI_API_KEY=your_gemini_api_key_here
```

## 🧪 Statistical Methods

### A/B Test Engine (`src/ab_testing.py`)

| Test | Metric | When Used |
|---|---|---|
| **Chi-Square (Pearson)** | Conversion Rate | Categorical outcome (0/1) |
| **Welch's Two-Sample T-Test** | Average Order Value | Continuous metric, unequal variances |
| **Chi-Square (Goodness-of-fit)** | Sample Ratio Mismatch | Guard-rail check on group sizes |

### Key Outputs

- **p-values** with 95% confidence threshold (α = 0.05)
- **Wilson Confidence Intervals** for conversion rate proportions
- **Analytical CI** (Welch–Satterthwaite) on mean difference
- **Cohen's d** (AOV effect size) and **Cohen's h** (conversion rate effect size)
- **Statistical Power** at current sample sizes
- **Minimum Detectable Effect (MDE)** at 80% power

## 🤖 Gemini AI Integration

The prompt passes **all statistical outputs** in a structured format:

```
Experiment context → SRM results → Conversion Rate stats → AOV stats → System recommendation
```

Gemini responds with a **6-section Executive Readout**:

1. 🔍 Experiment Validity
2. 📊 Results Snapshot (3–5 bullets for C-suite)
3. 📐 Statistical Interpretation (plain English)
4. 💰 Business Impact Estimation (revenue arithmetic)
5. ✅ Decision & Recommendation (GO / NO-GO / ITERATE)
6. 🛡️ Guardrails & Next Steps
